# PDF変換ツール 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** スマホとPCのブラウザで動き、GitHub Pages で公開できる PDF ツール（画像→PDF・結合・分割・回転・圧縮・プレビュー）を作る。

**Architecture:** ビルド不要の HTML/CSS/JavaScript（ES モジュール）。PDF の処理部品（`js/*.js`）は画面を知らない純粋な関数として書き、Node.js の標準テスト機能で自動テストする。画面部品（`js/ui/*.js`）は処理部品を呼び出し、エラーコードを日本語の文にして表示する。外部部品は `lib/` に同梱し、ブラウザとテストで同じファイルを読む。

**Tech Stack:** pdf-lib 1.17.1（PDF作成・編集）、pdfjs-dist 6.4.299 の legacy ビルド（プレビュー描画）、JSZip 3.10.2（ZIP作成）、Node.js 24 の `node --test`、http-server 14.1.1（確認用ローカルサーバー、npx で一時実行）

**Spec:** `docs/superpowers/specs/2026-10-05-pdf-tool-design.md`

## Global Constraints

- 変換はすべてブラウザ内で行い、ファイルをどこにも送信しない。外部サイト（CDN）から部品を読み込まない（`lib/` に同梱）
- 外部部品の版は固定：pdf-lib 1.17.1 / pdfjs-dist 6.4.299 / jszip 3.10.2。ライセンス文を `lib/LICENSES/` に置く
- pdf.js は **legacy ビルド**（古めの iPhone/Android のブラウザでも動く版）を使い、拡張子を `.mjs` から `.js` に変えて同梱する
- `package.json` は `"type": "module"`。npm の依存パッケージは入れない（`node_modules` を作らない）
- JavaScript は ES モジュール（`import`/`export`）。処理部品は `../lib/pdf-lib.esm.min.js` から import する
- pdf.js に PDF を渡すときは必ずコピー（`bytes.slice()`）を渡す（pdf.js は受け取ったデータを空にするため）
- 画面に出す日本語の文は `js/messages.js` だけが作る。処理部品は `PdfToolError`（`js/errors.js`）のコードだけを出す
- ブラウザ標準のポップアップ（`alert`）は使わない。エラーは画面内（`data-role="messages"`）に表示する
- ボタンなど押す部分は高さ 44px 以上（スマホで押しやすくするため）
- 保存するファイル名は `js/filenames.js` の `OUTPUT_NAMES` で作る
- コマンド例は PowerShell。コミットメッセージは日本語で、末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` を付ける

## 設計書からの補足・変更点

実装前の試運転で分かったことを反映した。設計書の意図は変えていない。

1. 画面担当 `main.js` が大きくなりすぎるため、画面ごとに `js/ui/*-screen.js` に分け、共通部品を `js/ui/common.js`、ページ一覧を `js/ui/page-grid.js` に置いた。`main.js` は画面の切り替えだけを担当する
2. テストしやすいよう、文の組み立て（`messages.js`）、ファイル名（`filenames.js`）、canvas の上限計算（`canvas-limit.js`）を独立した部品にした
3. iPhone の Safari には canvas の面積上限（約1677万画素）があるため、48メガピクセル級の写真やページは上限内に縮めてから描く（設計書の「画素数は減らさない」の例外）
4. パスワードなしで開けても「編集制限」付きのPDFは中身が暗号化されており扱えないため、エラー文を「パスワードや編集制限で保護されているため、対応していません」とした
5. ページ指定の範囲記号に `～`（Windows の日本語入力で出る全角チルダ）、`−`、`‐` も加えた
6. 手動確認用のサンプルファイルを作るスクリプト `tools/make-samples.js` を追加した（作ったファイルは Git に入れない）
7. URL の `#`（例 `#merge`）で画面を切り替える。スマホの「戻る」操作でホームに戻れるようにするため

## Review Focus

テストで押さえにくいが、利用者が最も遭遇しやすい入力・状況（各行のテストは担当タスクに追加済み）：

1. **iPhone の 48 メガピクセル写真** → 失敗せず、上限内に縮めて PDF にできること（Task 4 `canvas-limit.test.js`）
2. **同じPDFを2回選ぶ／プレビュー表示後に処理する** → pdf.js にデータを空にされず、結合などが成功すること（Task 5 `merge.test.js`、Task 8 `preview.test.js`）
3. **「区切る」で同じ範囲を2回書く（例 `1-3, 1-3`）** → ZIP 内のファイル名がぶつからず、両方入ること（Task 3 `filenames.test.js`）

5. **0ページのPDFや途中で切れたPDF** → 「読み込めませんでした」と表示されること（Task 1 `pdf-load.test.js`）

```js
export async function makePdf(pageCount, { rotations = {} } = {}) {
  const doc = await PDFDocument.create();
```

```js
// エラーの種類。処理部品はこのコードだけを出し、日本語の文は messages.js が作る
export const ErrorCode = Object.freeze({
  UNSUPPORTED_FILE: 'UNSUPPORTED_FILE',
  INVALID_PDF: 'INVALID_PDF',
  PASSWORD_PROTECTED: 'PASSWORD_PROTECTED',
  UNSUPPORTED_IMAGE: 'UNSUPPORTED_IMAGE',
  INVALID_PAGE_RANGE: 'INVALID_PAGE_RANGE',
  TOO_LARGE: 'TOO_LARGE',
  UNKNOWN: 'UNKNOWN',
});

export class PdfToolError extends Error {
  constructor(code, detail = {}) {
    super(code);
    this.name = 'PdfToolError';
    this.code = code;
    this.detail = detail;
  }
}

// どんなエラーも PdfToolError にそろえる。メモリ不足らしいものは TOO_LARGE にする
export function toToolError(err) {
  if (err instanceof PdfToolError) return err;
  if (err instanceof RangeError || /out of memory|allocation failed/i.test(String(err?.message))) {
    return new PdfToolError(ErrorCode.TOO_LARGE, { cause: err });
  }
  return new PdfToolError(ErrorCode.UNKNOWN, { cause: err });
}
```

`js/pdf-load.js`:
```js
import { PDFDocument } from '../lib/pdf-lib.esm.min.js';
import { ErrorCode, PdfToolError } from './errors.js';

// PDFを読み込む。他の処理部品は必ずこれを通して読み込む
export async function loadPdf(bytes) {
  let doc;
  let pageCount = 0;
  try {
    // パスワード付きでも一度読み込み、isEncrypted で確実に見分ける
    doc = await PDFDocument.load(bytes, { ignoreEncryption: true });
    if (!doc.isEncrypted) pageCount = doc.getPageCount();
  } catch (err) {
    if (err instanceof RangeError) throw new PdfToolError(ErrorCode.TOO_LARGE, { cause: err });
    throw new PdfToolError(ErrorCode.INVALID_PDF, { cause: err });
  }
  if (doc.isEncrypted) throw new PdfToolError(ErrorCode.PASSWORD_PROTECTED);
  if (pageCount === 0) throw new PdfToolError(ErrorCode.INVALID_PDF);
  return doc;
}

export async function getPageCount(bytes) {
  return (await loadPdf(bytes)).getPageCount();
}
```

```js
import { ErrorCode, PdfToolError } from './errors.js';

// スマホの日本語入力でも打てるよう、全角数字・全角記号・空白をそろえる
function normalize(text) {
  return text
    .replace(/[０-９]/g, (c) => String.fromCharCode(c.charCodeAt(0) - 0xfee0))
    .replace(/[，、]/g, ',')
    .replace(/[－~〜～−‐]/g, '-')
    .replace(/\s/g, '');
}

function fail(reason, extra = {}) {
  throw new PdfToolError(ErrorCode.INVALID_PAGE_RANGE, { reason, ...extra });
}

// 「1-3, 5」→ [[1, 2, 3], [5]]。カンマで区切った項目ごとに配列を作り、入力した順に返す
export function parsePageRange(text, pageCount) {
  const normalized = normalize(String(text ?? ''));
  const groups = [];
  for (const token of normalized.split(',')) {
    if (token === '') continue;
    const match = /^(\d+)(?:-(\d*))?$/.exec(token);
    if (!match) fail('syntax', { token });
    const start = Number(match[1]);
    let end = start;
    if (match[2] !== undefined) end = match[2] === '' ? pageCount : Number(match[2]);
    for (const page of [start, end]) {
      if (page < 1) fail('zero', { token });
      if (page > pageCount) fail('over', { page, pageCount });
    }
    if (start > end) fail('reversed', { token });
    const group = [];
    for (let page = start; page <= end; page++) group.push(page);
    groups.push(group);
  }
  if (groups.length === 0) fail('empty');
  return groups;
}

// 「取り出す」用：昇順に並べ、重複を除く
export function toSortedUniquePages(groups) {
  return [...new Set(groups.flat())].sort((a, b) => a - b);
}

// [1, 2, 3, 5] → 「1-3, 5」
export function formatPageRange(pages) {
  const sorted = [...new Set(pages)].sort((a, b) => a - b);
  const parts = [];
  let i = 0;
  while (i < sorted.length) {
    let j = i;
    while (j + 1 < sorted.length && sorted[j + 1] === sorted[j] + 1) j++;
    parts.push(i === j ? `${sorted[i]}` : `${sorted[i]}-${sorted[j]}`);
    i = j + 1;
  }
  return parts.join(', ');
}
```

```js
    case 'reversed':

  if (bytes < 1024 * 1024) return `${(bytes / 1024).toFixed(1)}KB`;

}
```

```js
export const PX_TO_PT = 0.75; // 1ピクセル = 0.75pt（pt は PDF の長さの単位。1pt = 1/72 インチ）
export const A4 = Object.freeze({ width: 595.28, height: 841.89 });
export const A4_MARGIN = 28.35; // 10mm

// 画像をページのどこに、どの大きさで置くかを計算する（単位は pt）
// mode: "a4" = A4に余白付きで収める（縮小のみ）、"fit" = ページを画像と同じ大きさにする
export function computePlacement(widthPx, heightPx, mode) {
  const w = widthPx * PX_TO_PT;
  const h = heightPx * PX_TO_PT;
  if (mode === 'fit') return { pageWidth: w, pageHeight: h, x: 0, y: 0, width: w, height: h };
  const landscape = widthPx > heightPx;
  const pageWidth = landscape ? A4.height : A4.width;
  const pageHeight = landscape ? A4.width : A4.height;
  const scale = Math.min(1, (pageWidth - 2 * A4_MARGIN) / w, (pageHeight - 2 * A4_MARGIN) / h);
  const width = w * scale;
  const height = h * scale;
  return { pageWidth, pageHeight, x: (pageWidth - width) / 2, y: (pageHeight - height) / 2, width, height };
}

// images: [{ bytes, type: "jpeg" | "png", widthPx, heightPx }] を1つのPDFにする
export async function imagesToPdf(images, mode, onProgress = async () => {}) {
  const doc = await PDFDocument.create();
  for (let i = 0; i < images.length; i++) {
    const { bytes, type, widthPx, heightPx } = images[i];
    const image = type === 'png' ? await doc.embedPng(bytes) : await doc.embedJpg(bytes);
    const p = computePlacement(widthPx, heightPx, mode);
    doc.addPage([p.pageWidth, p.pageHeight]).drawImage(image, { x: p.x, y: p.y, width: p.width, height: p.height });
    await onProgress(i + 1, images.length);
  }
  return doc.save();
}
```

```js
import { PDFDocument } from '../lib/pdf-lib.esm.min.js';
import { loadPdf } from './pdf-load.js';

// source（読み込み済みの文書）から、指定ページ（1から数える）だけのPDFを作る
async function buildFromPages(source, pages) {
  const out = await PDFDocument.create();
  const copied = await out.copyPages(source, pages.map((page) => page - 1));
  copied.forEach((page) => out.addPage(page));
  return out.save();
}

async function splitDoc(source, groups, onProgress) {
  const results = [];
  for (const pages of groups) {
    results.push({ pages, bytes: await buildFromPages(source, pages) });
    await onProgress(results.length, groups.length);
  }
  return results;
}

// 「ページを選んで取り出す」：指定ページを集めた PDF を1つ返す
export async function extractPages(pdf, pages) {
  return buildFromPages(await loadPdf(pdf), pages);
}

// 「1ページずつバラバラに」：[{ pages: [1], bytes }, { pages: [2], bytes }, …]
export async function splitEach(pdf, onProgress = async () => {}) {
  const source = await loadPdf(pdf);
  const groups = source.getPageIndices().map((index) => [index + 1]);
  return splitDoc(source, groups, onProgress);
}

// 「指定ページで区切る」：groups（例 [[1,2,3],[4,5]]）の項目ごとに PDF を作る
export async function splitByRanges(pdf, groups, onProgress = async () => {}) {
  return splitDoc(await loadPdf(pdf), groups, onProgress);
}
```

```js
import { degrees } from '../lib/pdf-lib.esm.min.js';
import { loadPdf } from './pdf-load.js';

// 角度を 0, 90, 180, 270 のどれかにそろえる（-90 → 270、450 → 90）
export function normalizeAngle(angle) {
  return ((angle % 360) + 360) % 360;
}

// rotations: { ページ番号: 追加する角度 }（例 { 2: 90 }）。元からの回転に足す
export async function rotatePages(pdf, rotations) {
  const doc = await loadPdf(pdf);
  const pages = doc.getPages();
  for (const [pageNumber, added] of Object.entries(rotations)) {
    const page = pages[Number(pageNumber) - 1];
    page.setRotation(degrees(normalizeAngle(page.getRotation().angle + added)));
  }
  return doc.save();
}
```

```js
import { PDFDocument } from '../lib/pdf-lib.esm.min.js';
import { loadPdf } from './pdf-load.js';
import { normalizeAngle } from './rotate.js';

// 「強く圧縮」の段階ごとの設定
export const STRONG_LEVELS = Object.freeze({
  low: Object.freeze({ dpi: 200, quality: 0.85 }),
  medium: Object.freeze({ dpi: 150, quality: 0.7 }),
  high: Object.freeze({ dpi: 100, quality: 0.5 }),
});

// 「画質そのまま」：中身の構造を整理して保存し直す
export async function compressLight(pdf) {
  const doc = await loadPdf(pdf);
  return doc.save({ useObjectStreams: true });
}

// ページの見た目の大きさ（回転を反映）。pdf.js と同じく CropBox（表示範囲）を使う
export function displaySize(page) {
  const { width, height } = page.getCropBox();
  const sideways = normalizeAngle(page.getRotation().angle) % 180 === 90;
  return sideways ? { width: height, height: width } : { width, height };
}

// 「強く圧縮」：各ページを JPEG にして作り直す。
// renderPage(ページ番号, { dpi, quality }) は、ページの見た目を JPEG にして返す関数（ブラウザでは preview.js が作る）
export async function compressStrong(pdf, level, renderPage, onProgress = async () => {}) {
  const setting = STRONG_LEVELS[level];
  if (!setting) throw new Error(`unknown level: ${level}`);
  const source = await loadPdf(pdf);
  const out = await PDFDocument.create();
  const pages = source.getPages();
  for (let i = 0; i < pages.length; i++) {
    const { width, height } = displaySize(pages[i]);
    const image = await out.embedJpg(await renderPage(i + 1, setting));
    out.addPage([width, height]).drawImage(image, { x: 0, y: 0, width, height });
    await onProgress(i + 1, pages.length);
  }
  return out.save({ useObjectStreams: true });
}
```

```js
// できたファイルを端末に保存させる【ブラウザ専用】
export function downloadBytes(bytes, fileName, mimeType = 'application/pdf') {
  const url = URL.createObjectURL(new Blob([bytes], { type: mimeType }));
  const link = document.createElement('a');
  link.href = url;
  link.download = fileName;
  document.body.append(link);
  link.click();
  link.remove();
  setTimeout(() => URL.revokeObjectURL(url), 60_000); // 保存が始まるまで少し待ってから解放する
}

// files: [{ name, bytes }] を1つのZIPにして保存させる【ブラウザ専用】
// JSZip は index.html の <script> で読み込まれ、globalThis.JSZip として使える
export async function downloadZip(files, zipName) {
  const zip = new globalThis.JSZip();
  const names = makeUnique(files.map((file) => file.name));
  files.forEach((file, i) => zip.file(names[i], file.bytes));
  downloadBytes(await zip.generateAsync({ type: 'uint8array' }), zipName, 'application/zip');
}
```

```js
import { limitSize } from './canvas-limit.js';
import { ErrorCode, PdfToolError } from './errors.js';

const JPEG_QUALITY = 0.92;

// canvas の内容を画像ファイルのデータ（Blob）にする。作れなかったら大きすぎと判断する
export function canvasToBlob(canvas, mimeType, quality) {
  return new Promise((resolve, reject) => {
    canvas.toBlob((blob) => (blob ? resolve(blob) : reject(new PdfToolError(ErrorCode.TOO_LARGE))), mimeType, quality);
  });
}

// 画像ファイルを正しい向きで描き直し、PDFに入れられる形（JPEG か PNG）にする【ブラウザ専用】
export async function decodeImage(file) {
  let bitmap;
  try {
    // imageOrientation: 'from-image' = スマホ写真の向き情報（EXIF）に従って正しい向きにする
    bitmap = await createImageBitmap(file, { imageOrientation: 'from-image' });
  } catch (err) {
    throw new PdfToolError(ErrorCode.UNSUPPORTED_IMAGE, { cause: err });
  }
  const { widthPx, heightPx } = limitSize(bitmap.width, bitmap.height);
  const canvas = document.createElement('canvas');
  canvas.width = widthPx;
  canvas.height = heightPx;
  const context = canvas.getContext('2d');
  const isPng = file.type === 'image/png';
  if (!isPng) {
    // JPEG は透明を扱えないため、先に白で塗っておく
    context.fillStyle = '#ffffff';
    context.fillRect(0, 0, widthPx, heightPx);
  }
  context.drawImage(bitmap, 0, 0, widthPx, heightPx);
  bitmap.close();
  const blob = await canvasToBlob(canvas, isPng ? 'image/png' : 'image/jpeg', JPEG_QUALITY);
  canvas.width = 0; // iPhone のメモリを早めに解放する
  canvas.height = 0;
  return { bytes: new Uint8Array(await blob.arrayBuffer()), type: isPng ? 'png' : 'jpeg', widthPx, heightPx };
}
```

```js
export async function runTask({ section, status, messages, after }, task) {
  const controls = [...section.querySelectorAll('button, input')];
  controls.forEach((control) => { control.disabled = true; });
  status.textContent = '処理中…';
  await nextPaint();
  try {
    return await task(async (done, total) => {
      status.textContent = `処理中… ${done}/${total}`;
      await nextPaint();
    });
  } catch (err) {
    reportError(messages, err);
    return undefined;
  } finally {
    status.textContent = '';
    controls.forEach((control) => { control.disabled = false; });
    after();
  }
}
```

```js
export function setupImagesScreen(section) {
  const input = byRole(section, 'input');
  const list = byRole(section, 'list');
  const messages = byRole(section, 'messages');
  const status = byRole(section, 'status');
  const run = byRole(section, 'run');
  let items = []; // [{ name, detail, image, url, thumb }]

  function refresh() {
    renderFileList(list, items, {
      onMove: (index, delta) => {
        items = moveItem(items, index, delta);
        refresh();
      },
      onRemove: (index) => {
        URL.revokeObjectURL(items[index].url);
        items = items.filter((_, i) => i !== index);
        refresh();
      },
    });
    run.disabled = items.length === 0;
  }

  input.addEventListener('change', async () => {
    const files = [...input.files];
    input.value = ''; // 同じファイルをもう一度選んでも反応するように空にする
    if (files.length === 0) return;
    clearMessages(messages);
    await runTask({ section, status, messages, after: refresh }, async (progress) => {
      for (let i = 0; i < files.length; i++) {
        try {
          const image = await decodeImage(files[i]);
          const url = URL.createObjectURL(new Blob([image.bytes], { type: `image/${image.type}` }));
          const thumb = document.createElement('img');
          thumb.src = url;
          thumb.alt = '';
          items.push({ name: files[i].name, detail: `${image.widthPx}×${image.heightPx}`, image, url, thumb });
        } catch (err) {
          reportError(messages, err, files[i].name);
        }
        await progress(i + 1, files.length);
      }
      warnIfLarge(messages, items.reduce((sum, item) => sum + item.image.bytes.length, 0));
    });
  });

  run.addEventListener('click', async () => {
    clearMessages(messages);
    const mode = section.querySelector('input[name="image-page-size"]:checked').value;
    await runTask({ section, status, messages, after: refresh }, async (progress) => {
      const pdf = await imagesToPdf(items.map((item) => item.image), mode, progress);
      downloadBytes(pdf, OUTPUT_NAMES.images);
    });
  });

  refresh();
}
```

```js
// 単色のPNG画像を作る（PNGの形式どおりにバイト列を組み立てる）
function solidPng(width, height, [r, g, b]) {
  const row = Buffer.alloc(1 + width * 3); // 先頭の1バイトは「フィルターなし」の印
  for (let x = 0; x < width; x++) row.set([r, g, b], 1 + x * 3);
  const raw = Buffer.concat(Array.from({ length: height }, () => row));
  const chunk = (type, data) => {
    const length = Buffer.alloc(4);
    length.writeUInt32BE(data.length);
    const body = Buffer.concat([Buffer.from(type, 'ascii'), data]);
    const crc = Buffer.alloc(4);
    crc.writeUInt32BE(crc32(body));
    return Buffer.concat([length, body, crc]);
  };
  const header = Buffer.alloc(13);
  header.writeUInt32BE(width, 0);
  header.writeUInt32BE(height, 4);
  header.set([8, 2, 0, 0, 0], 8); // 8bit・RGB
  return Buffer.concat([
    Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a]),
    chunk('IHDR', header),
    chunk('IDAT', deflateSync(raw)),
    chunk('IEND', Buffer.alloc(0)),
  ]);
}
```

```js
// 開いたPDFの後片付け（メモリの解放）
export async function closePreviewDoc(doc) {
  if (doc) await doc.loadingTask.destroy();
}

// ページを canvas に描く【ブラウザ専用】。端末の canvas の上限を超えないよう倍率を下げる
export async function renderPage(doc, pageNumber, scale) {
  const page = await doc.getPage(pageNumber);
  const wanted = page.getViewport({ scale });
  const limited = limitSize(wanted.width, wanted.height);
  const viewport = page.getViewport({ scale: scale * (limited.widthPx / wanted.width) });
  const canvas = document.createElement('canvas');
  canvas.width = Math.max(1, Math.floor(viewport.width));
  canvas.height = Math.max(1, Math.floor(viewport.height));
  await page.render({ canvas, viewport }).promise;
  page.cleanup();
  return canvas;
}

// 画面上で幅 cssWidth ピクセルになる小さな画像を描く【ブラウザ専用】
export async function renderThumbnail(doc, pageNumber, cssWidth) {
  const page = await doc.getPage(pageNumber);
  const width = page.getViewport({ scale: 1 }).width;
  return renderPage(doc, pageNumber, (cssWidth * (window.devicePixelRatio || 1)) / width);
}

// 「強く圧縮」用：ページを JPEG にする関数を作り、compressStrong に渡す【ブラウザ専用】
export function makeJpegRenderer(doc) {
  return async (pageNumber, { dpi, quality }) => {
    const canvas = await renderPage(doc, pageNumber, dpi / 72); // 倍率1 = 72dpi
    const blob = await canvasToBlob(canvas, 'image/jpeg', quality);
    canvas.width = 0;
    canvas.height = 0;
    return new Uint8Array(await blob.arrayBuffer());
  };
}
```

```js
const THUMB_CSS_WIDTH = 150;

// 要素が画面に近づいたら一度だけ onVisible を呼ぶ（遅延読み込み）
function whenVisible(element, onVisible) {
  const observer = new IntersectionObserver((entries) => {
    if (entries.some((entry) => entry.isIntersecting)) {
      observer.disconnect();
      onVisible();
    }
  }, { rootMargin: '300px' });
  observer.observe(element);
}

// PDFの全ページを小さな画像の一覧として grid に並べる。画面に見えたページから順に描く。
// decorate(tile, ページ番号) でボタンなどを付け足せる。戻り値は各ページの要素の配列（[0] が1ページ目）
export function buildPageGrid(grid, doc, pageCount, decorate = () => {}) {
  const tiles = [];
  for (let pageNumber = 1; pageNumber <= pageCount; pageNumber++) {
    const tile = document.createElement('div');
    tile.className = 'page-tile';
    const thumb = document.createElement('div');
    thumb.className = 'page-thumb';
    const label = document.createElement('span');
    label.className = 'page-label';
    label.textContent = `${pageNumber}`;
    tile.append(thumb, label);
    decorate(tile, pageNumber);
    whenVisible(tile, async () => {
      try {
        thumb.replaceChildren(await renderThumbnail(doc, pageNumber, THUMB_CSS_WIDTH));
      } catch (err) {
        console.warn(`${pageNumber}ページ目のプレビューを表示できませんでした`, err);
      }
    });
    tiles.push(tile);
  }
  grid.replaceChildren(...tiles);
  return tiles;
}
```

```js
// 「分割」画面
import { toToolError } from '../errors.js';
import { OUTPUT_NAMES } from '../filenames.js';
import { errorMessage } from '../messages.js';
import { formatPageRange, parsePageRange, toSortedUniquePages } from '../page-range.js';
import { getPageCount } from '../pdf-load.js';
import { closePreviewDoc, openPreviewDoc } from '../preview.js';
import { extractPages, splitByRanges, splitEach } from '../split.js';
import { downloadBytes, downloadZip } from '../download.js';
import { buildPageGrid } from './page-grid.js';
import {
  byRole, clearMessages, isPdfFile, notPdfError, readFileBytes, reportError, runTask, showMessage, warnIfLarge,
} from './common.js';

const PLACEHOLDERS = { extract: '例：1-3, 5', ranges: '例：1-3, 4-10' };
const HINTS = {
  extract: '取り出すページを入力するか、下のページをタップして選んでください。',
  each: '全ページを1ページずつ別々のPDFにして、ZIPファイルにまとめます。',
  ranges: 'カンマで区切った範囲ごとに別々のPDFを作り、ZIPファイルにまとめます。',
};

export function setupSplitScreen(section) {
  const input = byRole(section, 'input');
  const messages = byRole(section, 'messages');
  const info = byRole(section, 'info');
  const options = byRole(section, 'options');
  const hint = byRole(section, 'hint');
  const rangeInput = byRole(section, 'range');
  const rangeError = byRole(section, 'range-error');
  const run = byRole(section, 'run');
  const status = byRole(section, 'status');
  const grid = byRole(section, 'grid');
  let file = null; // { name, bytes, pageCount }
  let previewDoc = null;
  let tiles = [];

  const mode = () => section.querySelector('input[name="split-mode"]:checked').value;

  // 入力欄を読み取る。成功なら { groups }、失敗なら { message }（空欄のときは message が ''）
  function readRange() {
    if (rangeInput.value.trim() === '') return { message: '' };
    try {
      return { groups: parsePageRange(rangeInput.value, file.pageCount) };
    } catch (err) {
      return { message: errorMessage(toToolError(err)) };
    }
  }

  function refresh() {
    const current = mode();
    options.hidden = file === null;
    rangeInput.hidden = current === 'each';
    rangeInput.placeholder = PLACEHOLDERS[current] ?? '';
    hint.textContent = HINTS[current];
    const range = file !== null && current !== 'each' ? readRange() : {};
    rangeError.textContent = range.message ?? '';
    const selected = new Set(current === 'extract' && range.groups ? toSortedUniquePages(range.groups) : []);
    tiles.forEach((tile, i) => {
      tile.classList.toggle('selectable', current === 'extract');
      tile.classList.toggle('selected', selected.has(i + 1));
    });
    run.disabled = file === null || (current !== 'each' && !range.groups);
  }

  // 「取り出す」でページをタップしたら、選択を切り替えて入力欄に反映する
  function onTileTap(pageNumber) {
    if (mode() !== 'extract') return;
    const { groups } = readRange();
    const pages = new Set(groups ? toSortedUniquePages(groups) : []);
    if (pages.has(pageNumber)) pages.delete(pageNumber);
    else pages.add(pageNumber);
    rangeInput.value = formatPageRange([...pages]);
    refresh();
  }

  input.addEventListener('change', async () => {
    const selected = input.files[0];
    input.value = '';
    if (!selected) return;
    clearMessages(messages);
    if (!isPdfFile(selected)) {
      reportError(messages, notPdfError(), selected.name);
      return;
    }
    await runTask({ section, status, messages, after: refresh }, async () => {
      let bytes;
      let pageCount;
      try {
        bytes = await readFileBytes(selected);
        pageCount = await getPageCount(bytes);
      } catch (err) {
        reportError(messages, err, selected.name);
        return; // 前に選んだファイルはそのまま残す
      }
      await closePreviewDoc(previewDoc);
      previewDoc = null;
      tiles = [];
      grid.replaceChildren();
      file = { name: selected.name, bytes, pageCount };
      info.textContent = `${selected.name}（全${pageCount}ページ）`;
      rangeInput.value = '';
      warnIfLarge(messages, bytes.length);
      try {
        previewDoc = await openPreviewDoc(bytes);
        tiles = buildPageGrid(grid, previewDoc, pageCount, (tile, pageNumber) => {
          tile.addEventListener('click', () => onTileTap(pageNumber));
        });
      } catch (err) {
        console.warn(err);
        showMessage(messages, 'プレビューを表示できませんでした（分割はできます）。', 'info');
      }
    });
  });

  run.addEventListener('click', async () => {
    clearMessages(messages);
    const current = mode();
    const { groups } = current === 'each' ? {} : readRange();
    await runTask({ section, status, messages, after: refresh }, async (progress) => {
      if (current === 'extract') {
        const pdf = await extractPages(file.bytes, toSortedUniquePages(groups));
        downloadBytes(pdf, OUTPUT_NAMES.extract(file.name));
        return;
      }
      const results = current === 'each'
        ? await splitEach(file.bytes, progress)
        : await splitByRanges(file.bytes, groups, progress);
      const files = results.map((result) => ({
        name: current === 'each'
          ? OUTPUT_NAMES.eachPage(file.name, result.pages[0], file.pageCount)
          : OUTPUT_NAMES.range(file.name, result.pages),
        bytes: result.bytes,
      }));
      await downloadZip(files, OUTPUT_NAMES.splitZip(file.name));
    });
  });

  section.addEventListener('change', (event) => {
    if (event.target.name === 'split-mode') refresh();
  });
  rangeInput.addEventListener('input', refresh);
  refresh();
}
```

```js
            setTurn(pageNumber, (turns.get(pageNumber) ?? 0) + 90);
            refresh();
          }));
        });
      } catch (err) {
        console.warn(err);
        showMessage(messages, 'プレビューを表示できませんでした。', 'info');
      }
    });
  });

  byRole(section, 'all-cw').addEventListener('click', () => turnAll(90));
  byRole(section, 'all-ccw').addEventListener('click', () => turnAll(-90));

  run.addEventListener('click', async () => {
    clearMessages(messages);
    await runTask({ section, status, messages, after: refresh }, async () => {
      const pdf = await rotatePages(file.bytes, Object.fromEntries(turns));
      downloadBytes(pdf, OUTPUT_NAMES.rotated(file.name));
    });
  });

  refresh();
}
```

```js
// 「圧縮」画面
import { compressLight, compressStrong } from '../compress.js';
import { OUTPUT_NAMES } from '../filenames.js';
import { formatBytes, sizeChangeText } from '../messages.js';
import { getPageCount } from '../pdf-load.js';
import { closePreviewDoc, makeJpegRenderer, openPreviewDoc, renderThumbnail } from '../preview.js';
import { downloadBytes } from '../download.js';
import { byRole, clearMessages, isPdfFile, notPdfError, readFileBytes, reportError, runTask, warnIfLarge } from './common.js';

const RESULT_PREVIEW_WIDTH = 300;

export function setupCompressScreen(section) {
  const input = byRole(section, 'input');
  const messages = byRole(section, 'messages');
  const info = byRole(section, 'info');
  const options = byRole(section, 'options');
  const levels = byRole(section, 'levels');
  const run = byRole(section, 'run');
  const status = byRole(section, 'status');
  const result = byRole(section, 'result');
  const resultText = byRole(section, 'result-text');
  const resultPreview = byRole(section, 'result-preview');
  const save = byRole(section, 'save');
  let file = null; // { name, bytes }
  let output = null; // 圧縮後のPDF

  const mode = () => section.querySelector('input[name="compress-mode"]:checked').value;
  const level = () => section.querySelector('input[name="compress-level"]:checked').value;

  function clearResult() {
    output = null;
    result.hidden = true;
    resultPreview.replaceChildren();
  }

  function refresh() {
    options.hidden = file === null;
    levels.hidden = mode() !== 'strong';
    run.disabled = file === null;
    save.disabled = output === null;
  }

  // 圧縮後の1ページ目を表示して、画質を確かめられるようにする
  async function showResultPreview(bytes) {
    let doc = null;
    try {
      doc = await openPreviewDoc(bytes);
      resultPreview.replaceChildren(await renderThumbnail(doc, 1, RESULT_PREVIEW_WIDTH));
    } catch (err) {
      console.warn('プレビューを表示できませんでした', err);
    } finally {
      await closePreviewDoc(doc);
    }
  }

  input.addEventListener('change', async () => {
    const selected = input.files[0];
    input.value = '';
    if (!selected) return;
    clearMessages(messages);
    if (!isPdfFile(selected)) {
      reportError(messages, notPdfError(), selected.name);
      return;
    }
    await runTask({ section, status, messages, after: refresh }, async () => {
      try {
        const bytes = await readFileBytes(selected);
        const pageCount = await getPageCount(bytes);
        file = { name: selected.name, bytes };
        info.textContent = `${selected.name}（${formatBytes(bytes.length)}、${pageCount}ページ）`;
        clearResult();
        warnIfLarge(messages, bytes.length);
      } catch (err) {
        reportError(messages, err, selected.name);
      }
    });
  });

  section.addEventListener('change', (event) => {
    if (event.target.name === 'compress-mode' || event.target.name === 'compress-level') {
      clearResult();
      refresh();
    }
  });

  run.addEventListener('click', async () => {
    clearMessages(messages);
    clearResult();
    await runTask({ section, status, messages, after: refresh }, async (progress) => {
      if (mode() === 'light') {
        output = await compressLight(file.bytes);
      } else {
        const doc = await openPreviewDoc(file.bytes);
        try {
          output = await compressStrong(file.bytes, level(), makeJpegRenderer(doc), progress);
        } finally {
          await closePreviewDoc(doc);
        }
      }
      const change = sizeChangeText(file.bytes.length, output.length);
      resultText.textContent = change.text;
      resultText.classList.toggle('grew', change.grew);
      result.hidden = false;
      await showResultPreview(output);
    });
  });

  save.addEventListener('click', () => downloadBytes(output, OUTPUT_NAMES.compressed(file.name)));

  refresh();
}
```
